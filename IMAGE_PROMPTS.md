# Bonani Bricks website — image prompts (Google Flow)

> **Status (21 Nov 2026):** all slots are filled with your Google Flow images, plus a 9-photo gallery on the Factory page (`public/images/gallery`). Use these prompts only if you want to replace an image — keep the same file name.

Make each image in Google Flow, then save it **with the exact file name** into the folder shown.
The site already has a brick-pattern placeholder in every spot — as soon as a file is added, it appears automatically (no code change).

**Tips**
- Save as `.jpg`, around 200–400 KB (compress with squoosh.app or tinyjpg.com). Use the size in each heading.
- Add this to the end of every prompt for a consistent look: *"photorealistic, natural daylight, Bangladesh setting, no text, no logos, no watermark"*.
- Brand colours to hint at where it fits: green `#008001`, red `#E1141B`, brick red `#99282A`.
- Where you have **real photos** of your factory, machine, team or blocks, use them instead — real photos build more trust than AI images.
